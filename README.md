## 🧭 关于我

我是一名来自**黑龙江科技大学计算机科学与技术专业**的学生，热爱开发项目，也喜欢研究一个系统究竟是怎样运转起来的。

我喜欢把脑海里模糊的想法，一点点变成可以运行、可以交互、能够解决实际问题的软件。从功能设计到代码实现，从界面打磨到项目展示，亲手推动一个项目向前，是我学习计算机最有成就感的部分。

在做应用的过程中，我也接触到了**编译技术**。写程序让我享受创造，研究编译则让我对代码背后的世界更加好奇：一段代码如何被理解、如何被转换，又如何更高效地执行。这样的好奇心，带着我走上了新的赛场。

**我希望自己既能把一个功能做出来，也能逐渐讲清楚它为什么这样工作。**

## 🌱 现在的我，还在练习这些事

- **把项目做扎实。** 关注功能之外的体验、文档与可维护性，让别人也能看懂和使用自己的成果。
- **把原理学明白。** 顺着实际问题继续研究编译技术与系统实现，补上那些曾经只会用、却没想透的知识。
- **把经验留下来。** 尝试用代码、README 和技术文章，记录实现过程与踩过的坑。
- **把合作做好。** 学习更早沟通、清晰分工，也学习表达自己的需求，让共同完成一件事成为可能。

## 🎧 代码之外，也有情绪和音乐

我喜欢听**薛之谦**的歌。有时候，一段旋律会陪我走过比想象中更难熬的夜晚。那些说不清楚的失落，在歌里好像也有了可以安放的位置。

我的性格不太容易用一个词概括：有时候喜欢独处，有时候又很想融入热闹；会因为一点进展开心，也会因为一次失败难过很久。我还在学习怎样和这样的自己相处。

我会经常 emo，也会在事情没做好的时候反复回想。如果准备得再充分一点，如果当时换一种表达，如果再坚持一会儿，结果会不会不同？有些遗憾，我确实需要很久才能放下。

参加“互联网+”时，商业计划书、PPT 和现场答辩都由我一个人承担。拿到省级铜奖以后，我既知道自己为此付出了很多，也清楚地感受到，靠一个人继续往上走，已经很吃力了。

我曾经很纳闷，为什么一直没能遇到配合得很好的队友，为什么许多事情到最后还是自己扛。现在，我也开始把目光放回自己身上：有没有把目标说清楚，有没有及时沟通，有没有给别人参与和发挥的空间？这些问题，我还在慢慢寻找答案。

我依然希望自己变得更强，拥有更扎实的技术，做出更完整的项目。同时，我也希望遇到愿意认真做事的伙伴，一起讨论、一起承担，在遇到困难的时候有商有量地继续往前走。

低落的时候，我会听听老薛的歌，给自己一点缓冲。等情绪慢慢过去，再打开编辑器，改掉一个问题，补上一段代码，或者学会一个新的知识点。有时候，重新开始就是这样具体的一小步。

**我始终相信：打不倒我的，只会让我更强大。**

对我来说，这意味着在难过之后，仍然愿意再试一次。

## 🤝 如果我们刚好同路

如果你也喜欢开发项目，对编译技术或智能应用感兴趣，欢迎来交流。一个具体的问题、一条改进建议，或者一次认真的代码讨论，都可能成为合作的开始。

你可以在相关项目中提交 **Issue**，也欢迎通过 **Pull Request** 一起改进代码。我希望在分享自己所学的同时，也能认识更多愿意交流、认真做事的人。

如果我的某个项目恰好帮到了你，欢迎为它点一颗 **Star** ⭐。也欢迎告诉我哪里还可以做得更好。
